# Transit Event 공통 장소 안내

행사는 트랜짓 라운지에서 열린다. 새 행사 접수에서는 장소·주소·주차 가능 여부를 묻지 않는다. 행사마다 받는 정보는 행사명·소개, 날짜·시간, 추천 대상, 프로그램, 참가비·신청 방법이다.

## 고정 정보와 출처

장소는 트랜짓 라운지, 주소는 테헤란로34길 21-8 · 2층이다. 역삼역 2호선 1번 출구에서 도보 7분이라는 안내와 주차 안내는 사용자가 지정한 Figma 문구를 따른다. `pattern-catalog.json`의 `venue-guide`가 고정 정보·문구·지도 출처의 기준이다. 장소나 운영 정책 변경 요청이 오면 이 기준과 Figma를 함께 갱신한다. [사용자 지정 장소 안내](https://www.figma.com/design/oloM9zVU0XkiwIYXcIT23R/Transit-Lounge?node-id=3049-694)

## 페이지 구성

기본 세트는 표지 → 행사 맥락 → 일시·가격 → 추천 대상 → 프로그램 → 장소 안내 → 신청 CTA의 7장이다. 프로그램 등이 길어지면 페이지를 추가하고 장소 안내와 CTA를 뒤에 둔다. 아트보드 이름은 `TL/Event/S01/P06/Venue-Guide`, `TL/Event/S01/P07/CTA`를 따른다. S02~S04도 같은 순서다. 실제 페이지가 추가되면 P 번호를 다시 매긴다.

장소 안내에는 카탈로그의 `fixed_content`와 `asset_sources` 중 해당 시안의 지도를 자동으로 채운다. `event-job.json`을 새 초안의 기본값으로 사용한다. 과거 6장 초안에 적용할 때는 프로그램과 CTA 사이에 이 페이지를 넣고 고유 페이지 ID, 아트보드 P 번호, `deliverables[].cards`를 갱신한다. 수정한 페이지의 이전 render·QA·승인은 다시 검사한다.

## 지도 제작과 검사

- 새 콘텐츠에서는 해당 시안의 `Asset/venue-map` 프레임 영역만 2배 PNG로 내보내 작업 폴더에 보관하고 같은 984×524 영역에 넣을 수 있다. 지도 원본의 외곽 벡터·클리핑까지 카드의 본문으로 계수하지 않는다. 전체 카드는 제목과 보조문구를 편집 가능한 TEXT로 제작한다.
- 원본 지도는 SVG에서 가져온 화면 밖 도형과 라벨도 포함한다. 복제한 벡터 지도를 그대로 쓸 때는 전체 노드의 폰트·클리핑 검사를 실제로 통과해야 한다. 이미지로 쓸 때는 지도 내부의 주소·역명·경로·작은 글씨를 화면으로 검수한다.
- 지도 영역은 카드 기준 x48, y461, 폭984, 높이524. 라벨 40px Medium/60px, 제목 56px Bold/84px, 하단 보조 40px Medium/60px이며 모두 Neulis Alt다. 콘텐츠 전체 높이는 820px이다.
- 원고 한도는 라벨 5자/1줄, 제목 20자/1줄, 보조 26자/1줄이다. 공백·부호를 포함한다. 문구는 고정본을 쓰며 실제 줄 수와 넘침도 확인한다.
- 원본 Figma 링크는 초안의 `asset_ref`로 쓸 수 있다. 실제 제작 후에는 지도 파일 경로 또는 실제 자산 참조로 갱신한다. `render.asset`에 실제 지도 노드의 경계·가시성·클리핑·사용 자산 ref와 카탈로그의 `source_ref`를 기록한다. `captureFrame`의 `roles.asset`에 `node_id`, `ref`, `source_ref`를 넘기면 실측 정보를 수집한다.
- 최종 화면에서 길 안내·주소·주차 문구와 지도가 일치하는지 확인한다. `visual_review`는 이 검수 후에만 통과로 기록한다.
