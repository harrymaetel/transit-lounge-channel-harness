# 트랜짓 라운지 채널 디자인 시스템 v0.3

## 근거와 상태

Figma Transit Lounge, 파일 `oloM9zVU0XkiwIYXcIT23R`, SNS 페이지 `2878:1103`, 섹션 `2901:8816`을 2026-10-30 재확인했다. 서체 유지, 제목/본문/보조 분리, 구조화된 목록 레이아웃은 현재 사용자가 확정한 제작 규칙이다. 아래 픽셀 값은 현재 템플릿의 관찰값이며 브랜드 전체의 불변 토큰을 새로 승인한 것은 아니다.

## 고정 요소와 콘텐츠 영역

- 1080×1350, 좌우 기본 여백 48px, 상단 브랜드 헤더 y=80px, 콘텐츠 폭 984px.
- 헤더 왼쪽 Transit, 오른쪽 카테고리. 이 헤더를 콘텐츠 제목으로 대체하지 않는다.
- 콘텐츠 블록은 가변 높이로 중앙에 배치한다. 블록 안에서는 제목→본문/요소→보조 순서. 글이 짧아지면 고정 648px 텍스트 상자로 여백을 만들지 말고 HEIGHT + 세로 Auto Layout을 쓴다.
- 일반 블록 간격 40px. 라벨과 제목은 12px. 본문 길이에 따라 블록 전체가 이동하므로 특정 y 좌표를 모든 카드에 강제하지 않는다.
- 기본 콘텐츠 높이 예산 860px, 로고와 겹치지 않는 템플릿 영역을 사용한다. 표지·사진 오버레이는 해당 시안의 안전영역을 따른다.
- 하단 로고 락업은 원본 벡터를 유지한다. 보조문구와 별도 요소다.

## 서체 역할

모든 아래 역할의 family는 **Neulis Alt**다.

| 역할 | 크기/굵기 | 행간 |
|---|---|---|
| 브랜드 헤더 | 40 Regular | 120% |
| 본문 카드 제목·질문·CTA 제목 | 48 Bold | 150% |
| 추천 대상·프로그램·곡 순서 제목, 행사명 | 56 Bold | 150% |
| 일반 본문·목록 항목·CTA 안내 | 48 Medium | 150% |
| 일반 보조·출처·분류 라벨 | 40 Medium | 150% |
| 곡 아티스트·연도 | 28 Medium | 150% |
| 시리즈 표지 | 90 Bold | 90% |
| 표지 선곡자·회차 | 36 Regular | 120% |
| 인물 표지 역할·이름 / 훅 | 32 Bold / 72 Bold | 120% |
| 사진 위 인용 | 56 Bold | 120% |

행사 일시는 S01 56px, S02~04 48px로 관찰된다. 운영 기본은 48px이며 S01을 복제하는 작업은 해당 크기를 유지하고 실측 검수한다. 역할별 한도는 [pattern-catalog.json](pattern-catalog.json)이 단일 기준이다. 폰트 로드·혼합 스타일·데스크톱 대체 경로는 [font-workflow.md](font-workflow.md)를 읽는다.

## 색상·이미지·요소

기존 변수 바인딩과 자산을 복제해 사용한다. 피치 배경 main/05(#FED9C4), 진한 텍스트 #1C1A17의 90/70/50% 단계, 목록 카드의 더 진한 피치 약 #FFC9AB가 현재 관찰된다. 사용 가능한 원본 변수를 우선하고 새 글로벌 색상 토큰으로 자동 승격하지 않는다. 오렌지 CTA는 해당 시안 배경을 유지한다.

공간·사람·행사의 실제 사진을 우선한다. 음악 카드는 페이지 중앙에 하나씩 배치한다. 520×520 앨범 이미지 아래에 곡명과 아티스트 · 발매연도를 배치하고 곡과 앨범아트의 대응을 확인한다. 이미지 권한과 텍스트 대비를 검수한다. 구조별 치수는 [element-patterns.md](element-patterns.md), 카테고리 흐름은 [page-patterns.md](page-patterns.md)를 따른다.

## 템플릿 사용 원칙

기존 카테고리·세트·역할의 최신 프레임을 찾고 복제한다. 이후 슬롯과 반복 요소별로 내용을 넣는다. Figma를 다시 수정했다는 사용자 알림이 있으면 현재 프레임 구조부터 재확인한다. 이 문서의 예시 원고·인물·날짜·가격·음원 정보는 새 콘텐츠의 사실 근거가 아니다.


## 제작 안정성

텍스트를 resize한 뒤 textAutoResize=HEIGHT를 다시 설정한다. 부모에 삽입한 뒤 세로 HUG가 유지되는지 읽어 확인한다. 표지의 포스터 프레임은 TEXT와 달리 700×937 FIXED를 유지한다. 전체 카드는 1080×1350 고정이다. 자세한 구조 분기는 figma-production.md를 따른다.

사용할 슬롯이 템플릿에서 숨겨져 있다면 해당 슬롯과 필요한 조상을 확인해 표시한다. 불필요한 숨김 원고는 새 복제본에서 제거한다. 문자열 일치만으로 헤더를 일괄 삭제하지 않는다. Transit과 카테고리는 별도 역할 ID로 보존하며, 사진 문구는 얼굴을 피하고 보조문구까지 대비를 확보한다.
