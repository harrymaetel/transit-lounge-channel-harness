# 조건별 요소와 배치

## 역할을 노드로 분리

`BrandHeader` / `Content` / `Logo`를 구분한다. Content는 `Eyebrow?` → `Title` → `Body 또는 Items` → `Support?` 순서다. Title/Body/Support 각각 별도 TEXT 노드로 둔다. 필요 없는 슬롯은 생략하고 빈 줄로 구조를 흉내 내지 않는다.

원본의 관찰값을 유지하면서 콘텐츠에 맞게 Auto Layout 높이가 늘어나도록 한다. WIDTH_AND_HEIGHT 본문이나 축소 폰트로 넘침을 숨기지 않는다. 일반 카드의 빈 줄은 문단 구분용이고 그만큼 줄 예산을 소모한다.

## 추천 대상 → audience-pills

참조: Event/Who-For `2944:44`, 항목 `2951:9596`.

- 작은 라벨(추천 대상) + 굵은 제목(참여하면 좋은 이유).
- 대상별 FRAME 1개, TEXT 1개. 세로로 최대 3개, 간격 16px.
- 항목 984×120, 모서리 100, 상하 padding 24. 48px Medium 한 줄을 중앙 정렬한다.
- 각 항목에는 독립된 독자 조건 하나. 20자/1줄 이내.
- 2줄이 필요하면 원고를 다듬거나 별도 2행 변형을 설계하고 검수한다. 현재 120px에 2줄을 넣으면 144+48px가 필요해 넘친다.
- 보조문구는 목록 아래 별도 슬롯이며 항목 안에 섞지 않는다.

## 프로그램 → numbered-pills

참조: Event/Program `2944:69`, 항목 `2951:9612`.

추천 대상의 둥근 카드 구조를 재사용하되 각 항목에 순서가 있다. 데이터는 order와 text를 나누고 화면에는 `01  활동`으로 렌더한다. 번호를 포함해 20자/1줄, 최대 3단계. 4단계 이상은 다음 Program 페이지로 이어지고 번호를 초기화하지 않는다. 병렬 추천 목록에 순서를 임의로 부여하지 않는다.

## 곡 순서 → album-track-rows

[Listening-Flow 페이지](https://www.figma.com/design/oloM9zVU0XkiwIYXcIT23R/Transit-Lounge?node-id=2980-10306) · [한 곡 카드](https://www.figma.com/design/oloM9zVU0XkiwIYXcIT23R/Transit-Lounge?node-id=2980-10358)

- 1080×1350 페이지에서 콘텐츠는 (48, 204), 984×942다. 40px 라벨과 56px Bold 제목 다음에 40px을 띄운다.
- 중앙 카드 하나를 (256, 400)에 568×746으로 놓는다. 카드 안쪽 (24, 24)에 520×520 앨범아트를 채운다.
- 이미지 아래 40px을 띄우고 곡명과 메타를 세로로 붙인다. 두 텍스트 노드의 폭은 520px. Neulis Alt Medium 곡명 48px/행간 72px, 아티스트 · 발매연도 28px/행간 42px.
- 곡명 24자, 메타 40자는 각각 한 줄의 원고 예산이다. 실제 폭에서 줄바꿈과 잘림을 확인한다. 정식 크레딧이 넘치면 편집자에게 별도 레이아웃 검토를 요청한다.
- 선곡 순서대로 한 페이지에 한 곡씩 배치한다. 감상 안내와 링크는 이어지는 감상 질문 또는 CTA 페이지에 둔다.

## 본문·인용·CTA

질문/제목→답변→출처, 관찰 제목→장면 설명→맥락, CTA 제목→행동/경로 순으로 분리한다. CTA 아래 긴 보조 설명이 생기면 앞쪽 정보 페이지로 이동한다. 인물 원문과 편집 해설을 분리하고 원문 한 문장은 quote-credit 패턴으로 중앙 문장 + 하단 출처를 사용한다.

## 넘침 대응

글자 예산 초과 → 사실을 보존하며 다듬기 → 동일 역할 페이지 추가 순서로 처리한다. 추천·프로그램 요소 4개 이상은 3개씩 분할한다. 2행 항목 같은 새 변형은 현재 패턴인 척 통과시키지 말고 명시적 패턴 정의·렌더 검수 후 카탈로그에 추가한다. Figma에서 사용자가 선택한 변형이면 Decision Log H 근거를 함께 남긴다.
