# SNS 카드 세트·페이지 패턴 v0.2

2026-10-30 Figma 지정 섹션을 다시 읽었다. 6개 카테고리, 15개 세트, 77개 카드다. 가로는 한 세트의 연속 페이지, 세로는 같은 구성의 시안이다. 기존 4/2/7/3/3/1~2장 기준을 아래 구성으로 대체한다. **장수는 상한이 아니다.**

## 공통 편집 구조

브랜드 헤더(Transit / 카테고리) → 콘텐츠 제목 → 주요 내용 → 보조문구 → 로고 순이다. 여기서 '상단 첫 문장'은 브랜드 헤더가 아니라 콘텐츠의 첫 문장이다. 제목은 Bold의 독립 텍스트 노드, 본문은 Medium, 보조문구는 더 작은 Medium으로 나눈다. 제목을 본문 첫 줄에 붙여 넣지 않는다. 짧은 CTA의 안내는 48px Medium, 일반 출처·보조는 40px Medium이다.

추천 대상·프로그램·곡 순서는 문단이 아닌 반복 요소를 쓴다. 표지, 사진 전용, 원문 한 문장 카드는 필요 없는 본문을 만들지 않는다. 원문 인용에서 일부를 제목으로 뽑을 때 발언 의미와 출처를 보존한다. 출처가 없는 예시를 실제 인물 발언으로 확정하지 않는다.

현재 Story-Quote, Mood-Copy, Listening-Prompt에는 제목이 아직 본문과 합쳐진 레거시 예시가 남아 있다. 향후 제작은 사용자 지시에 따라 분리한다. 이 문서는 Figma 원본을 수정했다는 기록이 아니다.

## 계수와 한도의 의미

- 표의 관찰값은 현재 S01 원고의 실제 글자 수와 명시적 줄바꿈 수다. 공백·문장부호 포함, CR/LF 제외, NFC 유니코드 코드 포인트 기준이다. 빈 줄도 한 줄로 센다.
- 이것은 서체의 물리적 최대 수용량이 아니다. 고정 높이 648px에 2줄만 적힌 카드도 있으며 높이÷행간으로 원고 줄 수를 부풀리지 않는다.
- 향후 운영 상한은 [pattern-catalog.json](pattern-catalog.json)의 슬롯별 max_chars/max_lines다. 문장 길이·한영 혼용에 따라 자동 줄바꿈이 달라지므로 렌더의 실제 줄 수와 overflow 검사가 필수다.
- 기본 제목 30자/2줄, 본문 100자/6줄, 보조 25자/1줄. 아래 역할별 규칙이 우선한다. 48px 본문 행간은 72px, 40px 보조는 60px이다.
- 긴 인용은 본문 158자/9줄까지 가능하지만 제목·본문·보조·간격 합계 860px 이내여야 한다. 제목 2줄 + 본문 9줄 + 보조 1줄은 932px이므로 실패다. 본문을 분할하거나 제목을 줄인다.
- 번호도 표시 글자 수에 포함한다. 프로그램은 '01  ' 4자를 포함해 항목당 20자/1줄이다.
- 제목과 본문의 합계를 하나의 글자 수로 검사하지 않는다. 항목별·슬롯별로 검사한다.

## 제작과 페이지 추가

1. 카테고리의 기준 흐름에서 필요한 역할을 선택한다. 동일 역할 반복 가능, 페이지 번호는 최종 순서대로 다시 매긴다.
2. 정보 구조로 패턴을 선택한다. 대상 목록→audience-cards, 순서 있는 활동→program-steps, 음원 목록→track-list. 단순 문장으로 강등하지 않는다.
3. 항목 4개 이상이면 3개씩 연속 페이지로 분할하고 마지막 페이지에 나머지를 둔다. 프로그램 번호와 곡 순서는 페이지를 넘어 이어진다.
4. 슬롯 또는 전체 높이를 넘으면 사실과 인용을 보존하는 범위에서 다듬고, 그래도 넘으면 페이지를 추가한다. 폰트 축소·말줄임·대체 서체로 맞추지 않는다.
5. 프레임은 `TL/{Category}/S{시안번호}/P{페이지번호}/{Role}`로 명명한다. 새 시안과 추가 페이지를 혼동하지 않는다.

## 관찰과 미확정 사항

현재 일부 Lines 표지 헤더는 Book, Link & Mingle 일부 헤더는 Event다. 하네스의 신규 제작은 선택한 카테고리 표기를 일관되게 적용하되, 기존 표기를 브랜드 명칭 변경 승인으로 해석하지 않는다. 인터뷰 S02 발화자 표기가 섞여 있고 Lines의 창작 예시 문장에 인물명이 붙어 있다. 레이아웃은 재사용하되 이름·인용 귀속·음원 연도·일정 등 사실은 별도 출처 확인 후 사용한다.

각 원본 프레임 ID는 [pattern-catalog.json](pattern-catalog.json)의 categories에 있다. 현재 Lines S02/S03의 원문·성찰 프레임은 교체됐으므로 오래된 ID를 재사용하지 말고 현재 이름으로 다시 찾는다.
