# 브랜드 코어

- 브랜드: Transit Lounge / 트랜짓 라운지
- 역할: 다양한 비즈니스로 확장하기 위한 연결 플랫폼
- 핵심어: 편안한 연결, 따뜻한 연결, 자연스러운 연결, 집중감 있는 연결
- 톤: 따뜻하고 담백하며 구체적이다. 과장된 성공담보다 사람·장소·과정의 실제 장면을 보여준다.
- 금지: 근거 없는 성과, 출처 없는 인용, 승인되지 않은 가격·일정·파트너 로고, 브랜드를 과도하게 설명하는 광고 문구.
- 시각 우선순위: 승인된 브랜드 문서 > Figma 운영 템플릿 > 채널별 규격 > 외부 레퍼런스.
- 사용자 확정 서체(2026-10-30): Neulis Alt. 제목 Bold, 본문·보조 Medium, 브랜드 헤더 Regular를 기본으로 하며 역할별 예외는 디자인 시스템을 따른다. 도구가 폰트를 못 읽어도 다른 서체로 자동 치환하지 않는다.
