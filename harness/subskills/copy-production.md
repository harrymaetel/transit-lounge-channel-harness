# 카피 제작

1. 원고의 사실·수치·고유명사·인용을 출처와 함께 잠근다. 템플릿의 인물명·인용 귀속·음원 연도는 출처 검증 전 사실이 아니다.
2. 카테고리별 흐름에서 페이지 역할과 pattern을 고른다. references/pattern-catalog.json의 슬롯 상한을 사용한다.
3. 상단 첫 문장을 제목으로 분리하고 본문과 보조문구를 독립 필드로 쓴다. 제목은 독자가 이 페이지에서 얻을 내용, 본문은 근거·설명, 보조는 출처·맥락·행동 안내다. 필요 없는 슬롯에 억지 문장을 만들지 않는다.
4. 추천 대상은 items[{kind:audience-pill,text}], 프로그램은 items[{kind:program-pill,order,text}], 곡 순서는 items[{kind:track-row,artwork_ref,title,meta}]다. 추천 조건·순서·곡별 정보를 문단으로 합치지 않는다.
5. 글자 수는 공백·부호 포함, 줄바꿈 제외. 빈 줄은 줄 수에 포함한다. 긴 원문을 잘라 한도에 맞추지 말고 페이지를 추가한다. 프로그램 표시 번호도 글자 수에 포함한다.
6. 캡션은 보충 맥락과 행동을, 대체텍스트는 장면과 정보 관계를 설명한다.
7. 최종본에 humanize-korean을 적용하고 의미·인용·수치를 다시 대조한다. 사용할 스킬이 없으면 그 사실을 기록하고 같은 보수적 검수를 수행한다.
