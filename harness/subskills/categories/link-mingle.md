# Link & Mingle

기준 흐름: 표지 → 대화 맥락 → 사진 인용 → 긴 인용 → 사진 인용 2장 → 실천 → CTA. 기준 장수는 제한이 아니다.

대화 카드의 질문/관점은 제목, 발화는 본문, 발화자는 보조로 분리한다. 사진 인용은 34자/2줄 이내. 실천은 실제 대화에서 도출한다. 사진 사용 동의와 원문을 확인하며 이미지 위 문장이 얼굴을 가리지 않게 한다.

references/page-patterns.md의 해당 카테고리 관찰값과 references/pattern-catalog.json의 슬롯별 운영 상한을 적용한다. Neulis Alt와 제목→주요 내용→보조 위계를 유지한다.
