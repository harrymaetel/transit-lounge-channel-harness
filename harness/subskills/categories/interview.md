# Transit Interview

기준 흐름: 인물 표지 → 긴 Q&A → 추가 질문 2장 → CTA. 기준 장수는 제한이 아니다.

질문은 Bold 제목, 답변은 Medium 본문, 역할·이름은 하단 출처다. 질문 수와 답변 길이에 따라 Q&A 페이지를 추가한다. 템플릿의 서로 다른 인물명이나 예시 답변을 실제 발언으로 재사용하지 않는다.

references/page-patterns.md의 해당 카테고리 관찰값과 references/pattern-catalog.json의 슬롯별 운영 상한을 적용한다. Neulis Alt와 제목→주요 내용→보조 위계를 유지한다.
