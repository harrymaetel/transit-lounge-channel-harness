# 콘텐츠 전략

각 작업은 다음을 확정한다.

- 목적: 인지도 / 이해 / 신뢰 / 방문 / 신청 / 재방문
- 1차 독자와 독자가 얻을 효용
- 카테고리와 채널, 게시 희망 시점
- 한 문장 메시지, 근거 1~3개, CTA 1개
- 시리즈 내 위치와 다음 콘텐츠 연결
- 성공 지표와 관찰 기간

주제 우선순위는 브랜드 적합성, 독자 효용, 근거 가용성, 시의성, 제작 가능성 순이다.

페이지 수는 목적과 자료량으로 정한다. 카테고리의 기준 흐름에서 필요한 역할을 선택하고 같은 역할을 반복할 수 있다. 원고·항목이 슬롯 상한을 넘으면 CTA 앞에 페이지를 추가한다. 추천 대상은 조건 카드, 프로그램은 순서 카드, 곡 목록은 앨범 이미지 행을 지정한다. 기준안 장수에 맞추려고 원문을 삭제하거나 서체를 축소하지 않는다.
