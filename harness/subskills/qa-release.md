# QA와 릴리스 게이트

## 차단 오류

출처 없는 사실·가격·일정·인용, 미확인 자산, 잘림·겹침·대비 실패, 오탈자, 잘못된 링크·CTA, 사용자 승인 누락을 차단한다.

추가 디자인 차단 조건:
- Neulis Alt가 다른 family로 치환됨, 제목 Bold/본문 Medium 등 역할별 굵기가 틀림, 실제 렌더 없이 폰트 사용을 확인했다고 기록함.
- 제목·본문·보조가 같은 텍스트 노드에 합쳐짐. 단, 사진 전용·원문 한 문장 등 선택 패턴의 빈 슬롯은 허용.
- 추천 대상·프로그램이 문단 하나로 출력됨, 곡 행에 앨범 이미지·곡명·메타가 분리되지 않음.
- 슬롯별 글자 수/실제 줄 수 또는 전체 콘텐츠 높이 초과, 반복 항목 3개 초과, 다음 프로그램 페이지에서 번호가 초기화됨.
- 예시 링크·임시 귀속·목업 원고를 검증된 실제 정보로 발행하려 함.

## 검사 층

1. 구조: validate로 패턴·필수 슬롯·항목 타입·장수 일치·명시적 줄바꿈·글자 예산 검사.
2. 내용: 사실·출처·카테고리·제목과 본문의 대응. 인물 직함·이름, 곡명·아티스트·연도, 링크를 확인한다.
3. 시각: 실제 렌더에서 폰트와 모든 노드/혼합 범위, 자동 줄바꿈, 텍스트 안전영역, 이미지 크롭, 하단 로고와의 간격을 확인한다. job.pages[].render에 노드·줄 수·폰트·요소 컨테이너·검사 근거를 기록한다.
4. 발행: 연결 도구·계정·권한·시간·대상·최종 파일·사용자 승인을 확인한다.

qa.typography와 qa.element_layout은 3번을 실제 수행한 뒤 true로 설정한다. validate는 기록의 일관성을 검사할 뿐 Figma에 접속하거나 이미지의 가독성을 자동 판정하지 않는다. check-ready가 true여도 외부 발행 권한은 별도로 필요하다.

## v1.2 실측 게이트

신규 캐러셀은 references/render-evidence.md의 canvas, font_check, text_nodes, header, logo, content_bounds, visual_review를 기록한다. 원고와 렌더된 문자를 NFC 정규화 후 대조한다. HEIGHT/균일한 행간/문단 간격 0에서만 높이로 줄을 계산하며 1.1px보다 큰 잔차, 명시적 줄보다 적은 측정 줄, 폰트 축소를 차단한다.

visible=true여도 부모가 숨김·opacity 0·클리핑 상태면 실패다. 헤더를 지운 페이지, 무너진 사진 프레임, HUG로 줄어든 포스터, 얼굴 가림, 배경에 묻힌 보조문구, 사진과 다른 설명, 남은 실명·인용 귀속을 확인한다. 시각 검사 값은 검사자가 실제 화면을 본 뒤에만 입력한다.

v1.0/v1.1 기록은 validate로 과거 계약을 확인할 수 있지만 신규 발행 준비에는 current_render_contract가 필요하다. 값을 추정해 채워 과거 실행을 v1.2로 승격하지 않는다.
